<h3>Brief Overview</h3>

<p> The goal of this project was to use machine learning to create a model that will predict the outcome of any NBA playoff series. Then using this model, I can find the probability of any team in the playoff bracket winning a series against any other team in the bracket. I then apply this to the 2024 NBA Playoffs to see the predicted probability of each playoff team advancing to each round based on the bracket structure.</p>
